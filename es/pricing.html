Pricing details

Questions buyers ask

What is an MCP execution?

An MCP execution is a completed tools/call operation. Initialization, discovery, tool listing, health checks, prompts, and resource reads do not consume execution capacity.

What is an API Unit?

For Enterprise licensing, one API Unit covers one production API or OpenAPI service with up to roughly 50 operations. An API with 51–100 operations uses two Units. Count every production API separately, then add the Units together. This reflects the API estate kept AI-ready, not an arbitrary count of MCP tools.

Why not charge by MCP tool?

Tool design is an architecture decision. HAPI should help teams design useful AI capabilities, not reward them for combining or removing tools to lower an invoice.

What happens when capacity is reached?

Self-service plans are designed to prompt an upgrade before capacity becomes a problem. Enterprise agreements use contracted capacity, negotiated bursts, and agreed review terms rather than surprise usage bills.

Can I use HAPI without creating an account?

Yes. Free HAPI is available for experimentation and low-volume use through npm/Bun, native binaries, and Docker. A production conversation starts only when you want more capacity or commercial capabilities.
